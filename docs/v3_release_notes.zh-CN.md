# V3：训练、推理与评估一致性

V3 在 V2 数据契约修正的基础上，处理窗口加载、特征预处理、预测对齐和回测统计中的正确性问题。保留 GPU 训练路线，不新增 CPU 训练模式。当前交付是经过本地正确性检查的代码候选版，尚未复现历史训练结果。

## 本次变更

| 环节 | V3 行为 |
| --- | --- |
| 窗口加载 | 将加载器拆到 `src/window_loader.py`；批次可以跨 Stage4 的人工 block 边界，每个样本窗口仍受所属会话约束。训练最多丢弃整个 split 的最后一个短批次；验证、测试保留尾批。 |
| 时间输入 | 保留 float64 绝对时间，先计算窗口内相对时间再转 float32；模型时间编码显式使用配置参数。 |
| 训练入口 | 校验可用批次数、特征维度、窗口长度及统计文件；普通验证必须覆盖全部可用样本。Stage6 要求可见 GPU。 |
| 共享预处理 | Stage3 与推理共用填充、成交量归一化和流通市值归一化实现；冻结有效参数，拒绝静默改变训练时的特征含义。 |
| 模型契约 | 记录有序因子、窗口规则、预处理参数、schema/统计文件指纹；完成训练后写入模型和权重指纹。旧契约、未完成训练或重复运行名不能直接混用。 |
| 预测输出 | 使用带原始 `end_row`、float64 `t_sec` 和身份信息的 `.npz`；按批构造窗口，并记录模型契约及源 CSV 指纹。 |
| 统计评估 | 按行号和时间戳对齐 Stage2 标签，严格遵守 `is_valid`；缺少预期会话、混用运行或异常对齐会报错。区分会话均值、合并样本指标和事后 Top-K 描述统计。 |
| 回测 | 阈值只从早于交易期的校准集取得；沿完整原始会话执行，缺少预测时持仓延续。末行报价无效且仍有仓位时失败，不回溯到此前报价补算平仓。 |
| 默认流程 | 单股票配置关闭跨股票归一化；Stage1.5 显式启用。Stage0 和 LightGBM 对照仍不进入默认主线。 |

主线标签入口仍为 `src/stage2_build_labels_clear.py`。另一个 tick 标签脚本属于历史实验，不应当作可直接互换的标签定义。

## 验证证据

本次在 Python 3.12.14、NumPy 2.3.5、pandas 2.2.3、SciPy 1.17.0 环境下执行正确性测试。`requirements-test.txt` 仅记录这些测试依赖。

- 43 项测试通过，包括 V2 的标签/时间测试，以及 V3 的加载器、预处理、预测格式和回测测试。
- Stage3 → Stage4 → 加载器的合成数据测试验证了打包窗口与推理预处理一致，训练统计只使用训练数据。
- 评估/回测入口测试覆盖缺失会话、错误运行身份、源报价变化、末行无效报价，以及测试集预测变化不影响验证集阈值。
- Python 源码编译、示例 JSON 解析、Shell 语法及 Git 空白检查通过。

运行方法（仓库根目录）：

```bash
python3 -m pip install -r requirements-test.txt
python3 -m unittest discover -s tests -v
```

测试中的数据均在临时目录生成，不包含真实行情。这些测试验证数据和控制流程，不等于模型训练或收益复现。

## 从 V2 迁移

1. 保留原项目和历史输出，将 V3 解压到独立目录。
2. 以新的 `.example.json` 为模板建立私有 `.local.json`，迁移数据路径、股票信息和日期。单股票运行保持 `stage3.feature_norm_map_path=null`。
3. 统一设置新的 `train.run_name`、`predict.run_name`、`backtest.run_name`。为中间文件指定新的输出目录，避免覆盖旧实验。
4. 当前没有 GPU 时，只执行上述正确性检查并审阅代码、契约和文档。
5. 将来具备兼容 GPU 环境后，从 Stage1 重新生成整条管线产物。V2 打包 schema/统计信息缺少新增预处理契约；旧模型和旧裸 `.npy` 预测不能直接用于 V3 评估链。

不应通过手工补写模型契约或改名旧预测来绕过兼容性检查。历史结果保留为归档证据，与 V3 重新生成的结果分开。

## 尚未验证的部分

- 当前环境没有 TensorFlow，也未执行 GPU 模型构建、训练、保存/重载、混合精度或多 GPU 验证。加权指标已统一展平预测、标签和样本权重以避免广播；其运行时数值对照也须在 TensorFlow 环境补验。
- CCC 使用各副本内的批次统计，并非全局批次 CCC；设备数、批大小会影响该目标的含义。
- 尚未进行完整 Stage1–5 合成数据端到端验证，也未核验原始因子生成过程是否包含未来信息。
- 回测仍假设同一行信号和报价成交，未建模延迟、排队、成交量约束、实际可卖空条件或完整资金分配。累计单笔收益之和不等于组合净值。
- 本版未复现任何历史指标，也未自动提交或发布到 GitHub。
