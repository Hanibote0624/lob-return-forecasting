## 展示方式

首页首先说明研究问题和可检查的设计，再呈现验证记录及其范围。主线保留 GPU 训练、单股票示例和已有因子输入；单目标正弦时间编码与历史其他模型版本分开描述。

公开材料不列未经当前版本复现的真实 IC、方向准确率、交易收益或模型优胜结论。80 项基础测试和 13 项模型/集成检查沿用 V6 记录，本阶段没有把它们重新标成新的 GPU 训练证据。V5 报告继续作为历史材料保留。

## 本轮检查范围

- 核对从 V6 压缩包恢复的源码及现有证据指纹。
- 将文档中的示例维度、目标区间和默认配置与 JSON/实现对照。
- 检查文档内相对链接、锚点、图片、代码围栏和模型图结构。
- 执行首页所示配置 dry-run，验证命令入口和默认阶段顺序。
- 查看生成的时间示意图，确认标签可读、未裁切且没有假装展示市场数据。
- 比对 V6/V7 文件字节，确认实现、测试、配置、依赖和既有数值报告未变。
- 检查交付清单，不包含市场数据、模型权重、本地配置或面试准备稿。

文档核对不等于重新执行全部数值测试。本轮没有 GPU、真实数据或 GitHub 托管 CI 验证。
