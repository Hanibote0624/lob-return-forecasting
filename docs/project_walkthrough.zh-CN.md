# 项目详解：从不规则盘口事件到可核对的预测

[返回中文首页](../README.zh-CN.md) · [架构](architecture.md) · [证据](evidence.md)

## 研究问题

项目关注一个具体问题：给定近期 Level-2 盘口数据中已有的因子，以及这些事件实际发生的时间，能否回归未来数秒的中间价收益？

原始行并非固定周期快照。同样是 64 行，在活跃时段与稀疏时段可能覆盖不同的时间长度。因此，事件顺序和实际经过时间都需要明确处理。公开版本保留单股票研究配置，输入原有因子，模型同时接收因子窗口与窗口内相对时间。

该问题首先是预测研究。是否能够转化为交易，还取决于信号产生后能否按假设价格成交，以及成本、延迟和风险约束。

## 怎样定义一个样本

一个样本以原始 CSV 的第 i 行为终点，历史输入为同一交易时段中的 W 行因子。模型的未来标签单独构造：找到时间落在 `t_i + 2.5` 到 `t_i + 3.5` 秒之间的有效参考价格，按事件等权求均值，再除以当前参考价格并减一。

参考价格优先采用有效买一卖一的平均值，报价不满足条件时按配置回退到最新成交价。中间价先保留 float64，不先舍入到三位小数。未来区间为空、当前价格无效或不满足完整未来覆盖条件时，标签无效。

因此，这里的目标有三点需要明确：它不是恰好 3 秒后的单点价格，不按时间停留长度加权，也不把缺失标签视为零收益。实际训练还会缩放和裁剪目标，原始收益另行保留。完整规则见[数据契约](data_contract.md)。

## 模型与设计取舍

模型对历史因子使用训练集均值和标准差，再投影到隐层空间；窗口内相对时间经过正弦/余弦编码，与因子表示相加。Transformer 处理窗口内交互，前向 LSTM 聚合序列，最后输出一个回归值。

选择这个结构的出发点是同时表示因子间关系、事件序列和真实时间跨度。这只是可检验的建模假设。当前仓库没有足够的统一口径结果证明它优于 LightGBM，也没有证明时间编码或 LSTM 一定带来增益。代码保留时间编码开关及池化替代选项，便于后续对照。

默认损失是加权 CCC。训练样本的权重依据原始收益绝对值与训练集 q90 的关系设置；这会改变训练强调的样本，因此模型选择仍记录无权重的验证集 Pearson。当前 CCC 实现限定单副本，避免把多个副本各自的 CCC 平均误当作整体 CCC。

## 三个具体工程问题

### 时间精度可能在模型前就丢失

仅在层内部写 `cast(float32)` 不够：混合精度可能已经在进入 `call()` 之前把输入转成低精度。V6 检查复现了两个例子：以 10000 为均值、1 为标准差处理 10000 与 10001，旧行为都得到 -16；8 秒和 8.001 秒的时间编码也可能相同。

修复对标准化和时间相位计算保护 float32，并在形成窗口相对时间前保留 float64。对应测试直接检查数值，而不是仅观察模型能否编译。此修复证明信息没有在这些环节被提前丢弃，不证明预测效果因此改善。

### 窗口筛选后，预测不能靠固定偏移对齐

历史跨度或事件间隔约束会删除部分终点，因此预测数组不一定覆盖所有连续原始行。如果仍用 `W-1` 偏移或按较短长度截断，预测可能与错误标签配对。

当前预测产物保存每个窗口的原始终点行号和绝对时间戳。评估用行号索引标签，并核对时间、数据身份及标签有效性。训练和推理共用因子预处理，也减少了两份实现逐渐偏离的风险。

### 同一个 horizon 名称可能对应不同目标

未来区间边界、价格选择规则或缩放参数改变后，文件夹名仍可能相同。当前代码将这些实际定义与统计文件指纹写入数据包、模型和预测，消费者发现不匹配就拒绝继续。

这提高了实验可追溯性，但不是所有产物的防篡改系统；大型 pack 数组没有逐字节全部签名，失败阶段可能留下部分输出，仍需按运行规则检查和重建。

## 如何验证这些设计

已有记录包括 80 项非 TensorFlow 回归测试、完整合成 Stage1—5 对照，以及 13 项模型组件/预测集成检查。独立参考实现以整数毫秒和逐行运算构造标签、特征填充及窗口，用来对照真实脚本的输出。

另一个关键检查只改变验证集与测试集数据，要求训练集统计不变。模型检查则覆盖两种精度策略、四种损失、保存加载，以及预测生成、复用和错误拒绝。

这些检查验证指定行为，不构成真实股票的样本外效果。Stage5 对生产数组值进行抽样，合成小数据才逐项穷举检查。记录与边界见[证据说明](evidence.md)。

## 当前可以下的结论

公开版本已经把标签语义、事件时间、窗口对齐和实验身份变成可检查的代码规则，并提供数值及故障测试。当前仍不能给出该版本在真实数据上的可靠收益指标，也不能据此声称策略可交易。

外部已有因子是否含未来信息尚须核实；完整 GPU 环境、原始数据实验、时间编码消融和匹配的基线对照仍需补充。可选回测保留为研究工具，其同一行信号执行、成交和资金模型的局限应与结果一起解释。
